`attr.s(these=...)` and `attrs.define(these=...)` now collect `attr.ib()` attributes written on the class body, after the *these* dictionary.
A name present in both places keeps the *these* definition.
Attributes on base classes are still ignored.
The private sentinel is removed from the class, so it can no longer show up as an instance value.
With `auto_attribs=True`, annotated class-body attributes are collected too.
